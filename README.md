# 永不熄屏幕

一个用于 Android 的屏幕常亮应用。可在应用内或通过快捷设置磁贴开启、关闭常亮锁。

## 功能

- 开启时由前台服务持有屏幕级 WakeLock；应用界面处于前台时也使用 `FLAG_KEEP_SCREEN_ON`。
- 关闭后释放常亮锁，系统按原有息屏时间工作。
- 开启时可在获授权后关闭自动亮度；关闭常亮时不会重新打开自动亮度。
- 通知栏提供关闭入口（通知是否显示取决于系统通知权限）。

部分厂商系统可能忽略后台的屏幕级 WakeLock。磁贴显示“常亮锁已开启”只说明锁已获取，不保证所有设备都不会自动熄屏。按电源键主动熄屏仍由系统控制。

## 构建

使用 Android Studio 打开项目根目录，配置 Android SDK 37 和 JDK 17，然后构建 `app` 模块。也可运行：

```powershell
.\gradlew.bat :app:assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/`。`local.properties`、密钥和构建产物不会纳入 Git。项目中的 Release 配置仅复用本机调试签名以方便个人覆盖安装；正式发布应使用自己的签名密钥。

## 实机验证

在 PLK110 / ColorOS 17 / Android 17 上，系统息屏时间设置为 15 秒：开启后，应用前台与切到桌面分别等待超过息屏时间，屏幕保持亮起；关闭后等待，屏幕正常熄灭。该结果不代表所有机型或长时间运行都能保持常亮。
